WHEN IT DOESN'T WORK

Troubleshooting & FAQ

Java or Bedrock — which one do I even have?+

If you bought it on a phone, console, or the Microsoft Store, it's Bedrock. If you launch it from the Minecraft Launcher and can install mods, it's Java. Both work on server 01 — just follow the matching tab.

Bedrock says it can't connect.+

Nine times out of ten the port is missing or wrong — it must be 19132, not 25565. Otherwise: fully restart the game (Bedrock caches failed servers), and make sure you're on the current version.

Can I join the modded server on Bedrock, or on plain Java?+

No and no. Server 02 needs Java Edition running the exact CurseForge modpack on NeoForge 1.21.1. Vanilla Java gets rejected, Bedrock doesn't speak the protocol at all.

"Outdated server" / "Outdated client" on server 01.+

Server 01 tracks the latest release. Set your launcher profile back to "Latest release" and relaunch. If a brand-new version just dropped, give us a few days to catch up.

The modded pack crashes or runs like a slideshow.+

Raise the instance's RAM to 6–8 GB (more than 10 GB actually makes it worse), update your GPU drivers, and let the pack finish its first-load shader and model baking before judging the frame rate.

Can I bring a friend?+

Small community, so: yes, if you vouch for them. Ask before you hand out the address and everyone stays happy.
